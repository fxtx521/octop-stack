# octop-stack

[English](./README.md) | **中文**

基于 [TencentCloud/Octop](https://github.com/TencentCloud/Octop) 的企业价值层：macOS / Windows 双端瘦客户端（可在本地文件夹上使用 AI），加云端管理工具（开号、授权、记账）。

**Octop 保持官方原版。** 本仓库不修改 Octop 源码，只调用官方 API（REST + MCP 网关）。官方升级永不冲突。（完整性已校验：2277 个文件，0 改动。）

## 仓库内容

- `云端管控实测/` — 纯 API 云端管控闭环实测：邀请码开号、最小权限自定义角色、按人记账、员工访问管理接口被 403 拒绝。在隔离实例（127.0.0.1:8099）上 9/10 项通过，生产实例未动。
- `client/` — Go 瘦客户端：登录云端 Octop、列出专家、提问对话。同一套代码编译 macOS 和 Windows 版。

## 原则

1. 绝不修改上游源码——只用 API/CLI，用 RECORD 哈希审计验证。
2. 每个功能都带端到端验证才算交付。
3. 测试全部跑在隔离实例上，生产数据零接触。
